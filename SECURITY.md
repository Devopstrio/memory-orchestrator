# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

To report a vulnerability, please do NOT open a public GitHub issue. Instead, email **security@devopstrio.com**.

We pledge to triage your report within 48 hours and provide a remediation timeline.
